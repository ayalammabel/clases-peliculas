# Clases de Película

Visualización interactiva de los resultados cualitativos de Clases de Película.

## Estructura

- `index.html`: estructura principal de la visualización.
- `css/styles.css`: estilos de la interfaz.
- `js/app.js`: lógica e interacciones.
- `data/`: datos procesados utilizados por la visualización.
